# 🗨️ TCP Chat Server in C
A simple multi-client chat server built using C and socket programming on Linux. This project demonstrates real-time communication between multiple machines over TCP.

**🚀 Features**
Real-time message broadcasting to all connected clients

Basic command-line interface

Written in C using low-level sockets API

**🛠️ How It Works**

The server listens for incoming TCP connections on a specified port.

Messages sent by one client are relayed to all other connected clients.

🧪 **Requirements:**
GCC compiler,  Linux environment

**🏁 Getting Started**

**Compile -->**

gcc -o chat_server.c server 

gcc -o chat_client.c client

**Run-->**

Start the server:

./chat_server

Connect a client:


./client <server_ip>
